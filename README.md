# Grocery Shopping List

A simple Python command-line application that allows users to manage a grocery shopping list.

## Features
- Show all grocery items
- Add new items to the shopping list
- Remove items by entering their item number
- Exit the program

## Python Concepts Used
- Functions
- Lists
- For loops and while loops
- If-elif-else statements
- User input
- List methods (`append()` and `pop()`)

## Initial Shopping List
- Milk
- Bread
- Eggs

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python grocery_shopping_list.py
```
